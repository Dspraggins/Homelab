# Homelab

**David Spraggins**

A home lab that builds a small company's IT environment from scratch: virtualisation, networking, Active Directory, Microsoft Entra ID, Intune, security, monitoring, and backup. Each chapter documents what was built, what broke, and how it was fixed.
